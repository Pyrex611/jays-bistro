# Jay's Bistro — ordering platform

Mobile-first food ordering for Jay's Bistro (Makurdi, NG). Customers browse, build a tray and check out on WhatsApp; an AI concierge can answer questions and fill the tray.

React 19 · Vite · Tailwind 3 · Vitest.

```
npm install
npm run dev        # local dev server
npm run lint && npm test && npm run build
```
